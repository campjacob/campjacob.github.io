## Unit Introduction and What You Will Learn

In week five, we will focus more on reviewing the code of ethics. This week continues last week's discussion about the evolution of the code of ethics. It will also begin some introspection on our own values and biases. Ruby and I are doing joined synchronous sessions for this class this week. Whether you are in her section or mine, if you generally attend classes in Toppenish, we will meet on Tuesday (9/22) at 5:30 in RAU. You are generally scheduled to be with either Claudia or Chris for SOWK 312 or 316 during this time, and they have graciously allowed us to come in and take over their sections for the evening. If you generally attend classes in the Tri-Cities, we will be meeting on Thursday (9/24) at 5:30 in the same classroom Liz uses for 316. You are normally in her class, and she has graciously agreed to let us take over her section as well. You only need to attend one day (depending on which campus you attend). We have some activities and instruction we'll go through.

The learning objectives for week five are:

- Identify key concepts in the NASW Code of Ethics Preamble
- Explore personal values systems
- Discuss ways in which values systems vary

## Unit Resources

The textbook for this class is Reamer (2023), _Ethical Standards in Social Work: A Review of the NASW Code of Ethics_ (rev. 3rd ed.). You can find the book on the publisher's website: [NASW Press](https://naswpress.org/product/53468/ethical-standards-in-social-work). This week you read the first chapter, which is Reamer's introduction to the code — where it came from and how the current version is put together.

A reminder about my textbook podcast: it is meant to be an option resource for you. It does not replace the reading, but if you find it helpful, you are welcome to listen. You can listen to this week's episode for this week's reading [Deep Dive on Chapter 1: How the NASW Code of Ethics Evolved](https://vsp.ink/podcasts/deep-dive-reamer-2023/01-how-the-nasw-code-of-ethics-evolved/), or listen to the entire series [Deep Dive: Reamer (2023)](https://vsp.ink/podcasts/deep-dive-reamer-2023/).
